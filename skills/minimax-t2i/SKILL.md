# MiniMax 文生图 Skill

## 功能
使用 MiniMax image-01 模型生成小说配图（封面、场景图、角色图）

## 使用方式

### 生成封面图
```
生图 封面：[场景描述]
```
例如：`生图 封面：未来城市霓虹灯光下的赛博朋克场景`

### 生成场景插图
```
生图 场景：[场景描述]
```
例如：`生图 场景：主角站在量子服务器前思考`

### 生成角色图
```
生图 角色：[角色描述]
```
例如：`生图 角色：40岁男性科学家，穿着实验室白大褂`

### 图生图（保持风格）
```
生图 参考图：[描述] 图片：[图片路径]
```

## 输出
- 图片保存到 `novels/<小说名>/characters/` 或 `novels/<小说名>/chapter_XX/`
- 返回图片路径和 URL

## 配置
需要配置 MiniMax API Token（已在 config/config.yaml 中配置）
