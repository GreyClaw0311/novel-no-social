# 小说写作 Skill

## 功能
使用 AI 生成小说正文内容，包括选题、大纲、正文写作

## 使用方式

### 搜索选题
```
写小说 选题：[关键词列表]
```
例如：`写小说 选题：人工智能,量子计算,赛博朋克`

### 生成大纲
```
写小说 大纲：[小说设定]
```
需要提供：标题、题材、主题、角色、背景、风格、走向

### 写作单话
```
写小说 正文：[章回] [话数] [meta内容] [上一话内容]
```

## 输出
- 选题：返回备选选题列表
- 大纲：返回故事章节规划
- 正文：返回约 3000 字的单话内容

## 配置
需要配置 MiniMax API Token（已在 config/config.yaml 中配置）
